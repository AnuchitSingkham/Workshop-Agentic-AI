ตั้งค่า MCP server

เปิด/ปิด MCP server ที่ chat จะเรียกใช้ได้ (Module 2.1 Utils, Module 2.2 Google Calendar มาให้ในตัว) หรือเพิ่ม MCP server ภายนอกของตัวเอง (ต้องรองรับ Streamable HTTP JSON-RPC) — หน้านี้ป้องกันด้วย admin token

ปลดล็อกหน้านี้

กรอก admin token เดียวกับหน้าตั้งค่า Key

MCP server ที่เปิดใช้งานได้

ปิดเครื่องมือไหนก็ได้ที่ไม่อยากให้ chat มองเห็น — server ในตัวปิดได้แต่ลบไม่ได้

เพิ่ม MCP server ภายนอก

ใส่ URL ปลายทาง (Streamable HTTP) ของ MCP server ที่อยากต่อเพิ่ม

ระวัง prompt injection ผ่านเครื่องมือ

ผลลัพธ์จาก MCP server ภายนอกจะถูกส่งกลับเข้าไปให้โมเดลอ่านโดยตรง — เพิ่มเฉพาะ MCP server ที่เชื่อถือได้ เพราะ server ที่ไม่น่าเชื่อถืออาจแฝงคำสั่งมาหลอกให้โมเดลทำสิ่งที่ไม่ตั้งใจ
