ตั้งค่า API key

key ที่ตั้งในหน้านี้จะเก็บไว้ใน Cloudflare KV (ฝั่ง server) แทนที่ค่าเริ่มต้นจาก GEMINI_API_KEY/OPENAI_API_KEY/OPENAI_COMPAT_API_KEY ที่ตั้งไว้ตอน deploy — เปลี่ยนได้โดยไม่ต้อง deploy ใหม่ (รวมถึง base URL ของ gateway แบบกำหนดเอง) หน้านี้ป้องกันด้วย admin token

ปลดล็อกหน้านี้

กรอก admin token ที่ตั้งไว้ผ่าน wrangler secret put ADMIN_TOKEN (ดู SETUP.md)

API key แต่ละ provider

key ที่กรอกจะไม่ถูกแสดงกลับมาเต็ม ๆ อีกครั้ง — เห็นแค่ 4 ตัวท้ายเพื่อยืนยันว่าใช่ key ที่ตั้งใจ

ความปลอดภัย

key ที่บันทึกจะใช้ได้ทันทีกับทุกคนที่คุยผ่านหน้า Chat/Telegram ของ worker นี้ — อย่าแชร์ admin token ให้คนที่ไม่ควรแก้ค่านี้ได้
